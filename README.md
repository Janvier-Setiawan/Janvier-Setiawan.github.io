# Janvier Setiawan - Portfolio Website

A minimalist portfolio website with tabbed navigation system, inspired by modern clean design principles.

## Features

- **Clean, minimalist design** with typography focus
- **Tabbed navigation system** (About, Work, Essays, Contact)
- **Smooth transitions** between content sections
- **Mobile responsive** design
- **Keyboard accessible** navigation
- **Hash-based routing** for direct tab linking
- **No traditional scrolling** - viewport-contained design

## Design Philosophy

This website follows a minimalist approach with:
- Ultra-clean layout with lots of white space
- Typography-focused design using Inter font
- Subtle visual indicators and smooth transitions
- Professional, academic aesthetic
- Fast loading and smooth interactions

## Technical Implementation

- **HTML5** semantic structure
- **CSS3** with Flexbox and Grid for layout
- **Vanilla JavaScript** for tab functionality
- **CSS Transitions** for smooth animations
- **Mobile-first responsive design**
- **Accessibility features** (keyboard navigation, focus states)

## Structure

```
├── index.html          # Main HTML structure
├── styles.css          # All CSS styles and responsive design
├── script.js           # JavaScript for tab functionality
└── README.md           # This file
```

## Browser Support

- Modern browsers (Chrome, Firefox, Safari, Edge)
- Mobile browsers (iOS Safari, Chrome Mobile)
- Graceful degradation for older browsers

## Local Development

1. Clone the repository
2. Open `index.html` in a web browser
3. Or serve via local web server for hash routing functionality

## Customization

- Edit content in `index.html`
- Modify styles in `styles.css`
- Adjust functionality in `script.js`
- Update contact links and personal information
